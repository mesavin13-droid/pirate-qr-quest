# Квест для Славы и Дениса

В приложении сохранены три готовых мира: **Роботы (Бипик)**, **Хэллоуин (Тыковка)** и **Зима (Снежок)**. Робот — основной квест с пронумерованным пазлом, а остальные темы и их раскраски доступны на главном экране.

## Возможности

- Три отдельных мира со своими героями, заданиями, фонами и прогрессом.
- Нижнее меню: «Играть», «Раскраска», «Слушать», «Сканер», «Родителям».
- В квесте Бипика робот собирается из пяти частей; печать включает основу и пять деталей с номерами.
- Для Тыковки и Снежка сохранены их изображения и задания; в «Раскраске» доступны тематические контуры на печать.
- Родитель может настроить места QR-кодов и загрузить фото-подсказки.
- Фото следующего места закрыто стираемым слоем и открывается после выполнения задания.
- QR-сканер принимает только следующий код. Если основная библиотека недоступна, приложение загружает её с резервного CDN.

## Подготовка

1. Выбери на главном экране Роботы, Хэллоуин или Зима.
2. В «Родителям» настрой места и фотографии для выбранной темы.
3. Распечатай QR-карточки и пазл/раскраску этого мира.
4. Прячь каждый бумажный фрагмент рядом с QR-кодом того же номера.

## Хранение и камера

Настройки, фотографии и прогресс сохраняются в localStorage текущего браузера. Автоматической облачной синхронизации между телефоном и планшетом нет. Для камеры открой сайт по HTTPS в Safari или Chrome и разреши доступ к камере.
