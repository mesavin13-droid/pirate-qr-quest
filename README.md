# 🏴‍☠️ Pirate QR Quest

Мобильный веб-прототип домашнего пиратского QR-квеста для детей 3–5 лет.

## Что уже работает
- Семь этапов квеста с заданиями на русском языке.
- Режим родителя: редактирование заголовков, подсказок, заданий и фотографий.
- Генерация QR-кодов, печать отдельных карточек и всех карточек.
- QR-ссылки открывают этап через `?stage=1` … `?stage=7`.
- Прогресс сохраняется в localStorage браузера.

## Запуск
Статический сайт: откройте `index.html` или импортируйте репозиторий в Vercel. Сборка не нужна.

## Важное ограничение
Фотографии, настройки и прогресс пока сохраняются локально в браузере. Загруженные фотографии не появятся на другом телефоне автоматически, даже если QR-ссылка откроется. До подключения облака не используйте QR-коды на другом устройстве как окончательный квест.

## Следующий этап: Supabase
Нужно подключить таблицы `quests` и `quest_stages`, Storage bucket `quest-photos`, общий прогресс и авторизацию родителя. Файл `supabase-setup.sql` содержит начальную схему таблиц и политики владельца. Её нужно проверить и дополнить до многопользовательского использования.

## Безопасность
Для детей 3–5 лет задания выполняются со взрослым. Не предлагайте лазать по мебели, подходить к горячим приборам, открывать окна или прятаться в опасных местах.
