# 🤖 Квест для Славы и Дениса — Собери Бипика

Самостоятельное мобильное веб-приложение для домашнего QR-квеста. В текущей версии оставлен только один сюжет — ремонт робота Бипика.

## Основные функции

- Исходный мобильный дизайн с нижним меню: «Играть», «Раскраска», «Слушать», «Сканер», «Родителям».
- Пять последовательных заданий и пять частей бумажного пазла.
- Главный робот постепенно собирается цветными фрагментами по мере прохождения этапов.
- Пять QR-кодов; сканер принимает только код ожидаемого этапа.
- Родитель настраивает места QR-кодов и может загрузить фотографии мест и финального приза.
- Фото-подсказка закрыта стираемым слоем; после открытия показывает место следующей карточки.
- Печать двух листов A4: основы с номерами и пяти деталей для вырезания.
- Русская озвучка заданий через возможности браузера.

## Как подготовить игру

1. Откройте «Родителям» и укажите места для пяти QR-кодов.
2. При необходимости добавьте фото мест и фото финального приза.
3. Распечатайте QR-карточки.
4. В разделе «Раскраска» распечатайте пазл: основу и детали.
5. Прячьте каждую деталь рядом с QR-карточкой того же номера.
6. Ребёнок сканирует QR, выполняет задание, забирает деталь и вклеивает её в пронумерованную ячейку.

## Хранение и публикация

Настройки, фотографии и прогресс сохраняются в localStorage браузера. Они остаются на том устройстве, где были добавлены; автоматической облачной синхронизации между телефоном и планшетом сейчас нет.

Это статический сайт на одном `index.html`. Для камеры нужен браузер с разрешённым доступом к камере и защищённый HTTPS-адрес.
