# Квест для Славы и Дениса — Собери Бипика

Мобильное веб-приложение для домашнего QR-квеста с одним героем — роботом Бипиком.

## Что внутри
- 5 последовательных заданий для детей.
- QR-карточки с прямыми ссылками на этапы, которые открываются обычной камерой телефона или встроенным сканером.
- Прогресс восстановления робота и пять пронумерованных деталей.
- Режим родителя: настройка мест, загрузка фото подсказок и фото места приза.
- Фото следующего места скрывается под защитным слоем и раскрывается после прохождения задания.
- Печать пазла на двух листах A4: основа и пять соответствующих ей пронумерованных деталей.
- Печать QR-карточек и озвучивание заданий на русском языке.

## Подготовка
1. Открой «Родителям».
2. Распечатай пазл и QR-карточки.
3. Спрячь каждый QR-код вместе с бумажной деталью такого же номера.
4. По желанию загрузи фотографии мест следующих карточек и места финального приза.
5. Ребёнок находит QR-коды по порядку, выполняет задания и вклеивает детали по номерам.

## Хранение
Статическое приложение; настройки, фотографии и прогресс сохраняются в localStorage этого браузера. Для игры используй тот же телефон или планшет, где были заданы фотографии и настройки.

## Запуск
Открой `index.html` или импортируй репозиторий в Vercel. Серверная сборка не требуется. Для камеры необходим HTTPS.
